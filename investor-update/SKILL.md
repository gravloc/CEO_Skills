## Steps
1. Gather metrics from Sheets, shipped work from Linear and GitHub, and
   milestones from MEMORY.md.
2. Draft: Headline, Metrics table, Progress, Challenges, Asks (intros,
   advice, hiring), Next month.
3. Be honest about misses. No invented numbers; mark unknowns as [TBD].
4. Save as a Doc and create a Gmail DRAFT only. Never send without approval.
